


# FNP Sales Analysis Dashboard

## Project Overview
This is an interactive Sales Analysis Dashboard built using Microsoft Excel to analyze sales performance, customer behavior, revenue trends, and product insights for an online gifting business.

## Key Insights
- Total Revenue: ₹35,20,984
- Total Orders: 1000
- Average Customer Spend: ₹3,520.98
- Revenue analysis by occasion, category, month, and city

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards
- Data Visualization

## Dashboard Features
- Interactive filters
- Dynamic KPI tracking
- Revenue trend analysis
- Top products and cities analysis
